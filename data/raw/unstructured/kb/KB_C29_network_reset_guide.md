# Resetting Device Network Settings for Persistent Connectivity Issues

**Department:** Technical Support  
**Last Updated:** 2026-06-30  
**Version:** 1.0

---

## Purpose

Generic troubleshooting guide for connectivity issues not resolved by a restart.

## Steps

1. Note current Wi-Fi passwords (they will be cleared).
2. Settings > General/System > Reset > Reset Network Settings.
3. Reconnect to Wi-Fi and re-enter mobile data APN if manually configured (rare on NovaTel-provisioned SIMs).
4. If mobile data still fails, contact care for network-side provisioning check.
