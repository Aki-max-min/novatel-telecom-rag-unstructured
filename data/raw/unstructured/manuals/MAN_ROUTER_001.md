## Box Contents

ONT, Wi-Fi router, power adapters, 1 fibre patch cord, quick-start card.

## Setup Steps

1. Connect the fibre patch cord from the wall outlet to the ONT.
2. Connect ONT to router via the LAN/WAN port using the supplied Ethernet cable.
3. Power on both devices; wait for the PON light to turn steady green.
4. Connect to the default Wi-Fi network printed on the router label and open 192.168.1.1 to set a custom password.
