## Summary

This release delivers a set of app, portal, and backend improvements as summarised below, along with fixes for issues reported in the prior release cycle.

## New Features

- Additional filter/search options in the relevant self-care section.
- Enhanced self-care flow for the most common customer requests in this category.

## Improvements

- Faster load times for the affected screens.
- Improved consistency between app and web portal behaviour.

## Bug Fixes

| Issue | Description | Customer Impact |
|---|---|---|
| Stuck status display | Status occasionally failed to refresh after backend update | Low — cosmetic only |
| Duplicate notification | Some customers received a repeat confirmation message | Low |

## Compatibility

Compatible with the current supported app and OS versions; no action required for most customers.

## Known Issues

A small number of customers on older app versions may need to update manually to see the latest changes.

## Migration / Upgrade Instructions

No manual migration is required; the update is delivered automatically via the standard app-store update or backend deployment.
