# Fraud and SIM-Swap Response Training

**Document ID:** TRN_003
**Department:** Security
**Category:** General (C01-C29)
**Last Updated:** 2026-03-20
**Version:** 1.0

---

## Learning Objectives

Agents can recognise fraud indicators and execute the emergency SIM-block procedure without delay.

## Red Flags

- Customer reports sudden loss of signal followed by unauthorised bank transactions
- Request to change registered email/address immediately before a SIM swap request
- Caller unable to answer standard security questions but pressuring for urgent action

## Immediate Action Protocol

1. Verify identity using alternate verification (not the compromised channel).
2. Block the SIM immediately if fraud is suspected — do not wait for full verification if there is clear and present risk.
3. Log as a P1 security incident per SOP_C18_FRAUD_RESPONSE.

## Assessment

Agents are certified only after passing a simulated fraud-call assessment with zero critical errors.
